# Network Traffic Analysis 🔒🌐

## Cybersecurity Blue Team Project
This project focuses on analyzing network traffic using Wireshark to understand packet behavior and core communication protocols.

### 🛠️ Tools Used
* Wireshark[cite: 1, 2]
* Windows OS
* Npcap

### 🎯 Objectives
* Understand and capture live network packets[cite: 2]
* Analyze IP and DNS traffic[cite: 3]
* Track TCP 3-way handshake and session flow[cite: 4]
* Identify TLS secure traffic and unencrypted HTTP requests[cite: 4, 7]

### 📂 Repository Structure
* `/screenshots` - Contains Wireshark capture outputs
* `/report` - Project documentation
* `/filters` - Display filters reference
